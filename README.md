# Quantum-Transmission-Through-a-Double-Barrier
This repository contains a Python implementation of quantum mechanical transmission through a one-dimensional double barrier potential using transfer matrix methods derived from boundary conditions.

## Features
- Exact calculation of reflection and transmission coefficients
- Handles real and complex wave numbers
- Fully modular and extensible (soon for nth barriers)

## Physics Background
The method is based on matching wave functions and their derivatives at
each interface, leading to a global transfer matrix:

(A0, B0)^T = Λ (A5, B5)^T

## Applications
- Resonant tunneling
- Quantum devices
- Teaching and learning quantum mechanics

- Python 3
- NumPy
